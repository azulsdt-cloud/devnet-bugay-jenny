## What is Git? What is GitHub? (explain like you're teaching a friend who's never used either)

Git is the version control or tool of GitHub. It saves the files or anything that's been modified to the files and transfer it to the GitHub. The problem that Git can solve is saving the files to avoid loss progress or files and then bring it to GitHub repository to save it. Without the Git commands, it can't pass or transfer the changes to your GitHub. Since GitHub is a platform use for collaboration and Git is for the commands for them to work together.
---

## Key vocabulary (in your own words)

- repository: It is your own GitHub space wherein you can access the files or code that you store and use for your activities. 
- commit: It is used to save the changes in your files. To ensure that your progress shows in the GitHub repository or branch. 
- branch: It is like a separate repository since it makes another space to your other activities to avoid mixing of files and progress. To make your work organize and easy to find.
- push / pull: Push is used to upload your changes in GitHub and Pull is to get or access the work of other collaborators. They are both commonly used for showing your project or progress.
- pull request: It is used to transfer your branch to the main branch or other branch. It combines your work to the other existing works. 
- merge conflict: A problem wherein the merge is not working and it cannot combine your works to the other branch.
